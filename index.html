This static website saves records only in your current browser's localStorage. It does not sync across devices. Deleting browser storage removes your data unless you exported a backup.

How to publish

Push these three files to a GitHub repository. In Settings → Pages, choose Deploy from a branch, select main and /(root), then save. The site will work as a static application without a server.

GitHub Pages does not itself scrape job sites, run a backend, store a shared database or send scheduled reminders.
